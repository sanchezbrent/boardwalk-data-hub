# Security reports

Do not open a public issue containing credentials, private source evidence or
unpublished data. Use GitHub's private vulnerability reporting when enabled by
the repository owner. If it is unavailable, contact a verified repository
maintainer privately before sharing details. No reporting address is invented here.

Only the latest reviewed 0.1.x source is the intended maintenance line. There is
currently no deployed plugin or production security support claim. Installation
is static, trusted first-party code with the host's browser privileges; this
contract is not a sandbox for arbitrary third-party plugins.
